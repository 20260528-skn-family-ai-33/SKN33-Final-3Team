# 해외시장뉴스 키워드 정제·지역 분리 사용 안내

`keyword_clean.py`는 해외시장뉴스 수집 결과(`news_raw.csv` 또는 `.parquet`)의 키워드(`kwrd`)를 검색·집계에 쓸 수 있게 정리합니다.

1. **정제(①)**: HTML 문자(`&#39;`), 해시태그(`#`), 따옴표, 공백, 영문 대소문자를 통일하고 붙어 있는 키워드를 나눕니다.
2. **지역 분리(②)**: `geo_dict.csv`로 국가·도시·권역을 찾아 별도 칸으로 옮기고 `중국경제 → 중국 + 경제`처럼 복합어를 나눕니다.
3. **연도 분리**: `2024`, `2026년`처럼 연도만 있는 키워드는 지우지 않고 언급 연도 칸(`kw_year`)으로 옮깁니다. (`2026년 전망` 기사는 작성일과 다루는 연도가 다를 수 있음)

원본 `kwrd`는 바꾸지 않고 결과 칸을 새로 추가합니다. 원본은 보관용이고, 정리 결과는 아래 칸들에 있습니다.

## 분류 기준과 사전 만드는 코드

동의어·대/중분류·예외·지역·불용어를 **어떤 기준으로 누가 정했는지**는 [`CLASSIFICATION_RULES.md`](CLASSIFICATION_RULES.md)에 있습니다.
사전 csv는 `build/` 폴더의 코드로 다시 만들 수 있고, `build/verify.py`로 저장된 파일·나눠 준 검수 파일이 코드 결과와 같은지 확인합니다.

## 실행

저장소 루트에서 실행합니다. `pandas`가 필요하고, `.parquet`을 읽으려면 `pyarrow`도 필요합니다.

```powershell
python backend/app/services/news_keywords/keyword_clean.py --input "news_raw.csv 경로" --since 2022-01-01
```

### 입력 데이터 준비

팀 수집 코드(`collectors/news/news_collect.py`)로 받은 `news_raw.csv`를 씁니다. 한 번에 전체를 받으면 API가 가끔 기사 목록 없이 응답해
멈추는 일이 있어 **연도별로 나눠 받은 뒤 기사 ID로 합쳤습니다** (`data/news/news_raw_20220101_20261013.csv`, 14,607건, 연도별 API 전체 건수와 일치).

```powershell
python backend/app/services/news_keywords/keyword_clean.py --input data/news/news_raw_20220101_20261013.csv
```

| 옵션 | 설명 |
|---|---|
| `--input` | 필수. 해외시장뉴스 수집 결과 `news_raw.csv` 또는 `.parquet` (`kwrd`, `natn` 컬럼 필요) |
| `--since` | 이 날짜 이후 기사만 처리 (`othbcDt` 기준, 예: `2022-01-01`) |
| `--geo` | 지역 사전 경로 (기본: 같은 폴더의 `geo_dict.csv`) |
| `--output-dir` | 결과 폴더 (기본: 저장소 루트 `data/news_keywords/`, git 제외) |

## 결과 파일

`news_keywords_clean.csv`: 기사 한 건이 한 행이며, 여러 값은 `|`로 구분합니다.

| 컬럼 | 내용 | 예 (2024-11-25 인도네시아 전기차 기사) |
|---|---|---|
| `kwrd` | 원본 키워드 | `인도네시아,이모빌리티,전기차,ev,electric vehicle,emobility` |
| `kw_clean` | ① 정제 후 키워드 | `인도네시아\|이모빌리티\|전기차\|EV\|ELECTRIC VEHICLE\|EMOBILITY` |
| `kw_topic` | ② 지역·연도를 뺀 주제어 | `이모빌리티\|전기차\|EV\|ELECTRIC VEHICLE\|EMOBILITY` |
| `kw_spike` | **급증 계산용 주제어**: `kw_topic`에서 블락 목록(`stopwords.csv`, 지금은 비어 있음)을 뺀 것 | `이모빌리티\|전기차\|EV\|…` |
| `kw_category` | ⑥ 분야 (대분류>중분류) | `산업·품목>품목 (→ HS 코드로 연결)` |
| `kw_year` | 키워드에 나온 연도 (언급 연도) | |
| `hs6` / `hs4` / `industry` / `product_source` | ③ 품목: HS 6단위(요구사항 기본) / 4단위 / 산업분류 / 채운 단계 | |
| `natn_code` | 기사 국가(`natn`)의 국가코드 | `ID` |
| `geo_country` | 키워드에서 찾은 국가코드 (참고용) | `ID` |
| `geo_city` / `geo_region` | 키워드에서 찾은 도시 / 권역 | |
| `country_all` | **국가 필터용**: `natn_code` 기준. 기사 국가가 KOTRA 본사·전세계일 때만 `geo_country`로 보충 | `ID` |

`news_keywords_report.json`: 키워드 종류 변화, 규칙별 적용 건수, 복합어 분리 상위 30개, 기사 국가 반복 비율 등.

## 규칙

| 규칙 | 예 |
|---|---|
| HTML 문자·해시태그·따옴표 제거 | `#틱톡` → `틱톡`, `&#39;Buy Canadian&#39;` → `BUYCANADIAN` |
| 공백·대소문자 통일 (한글 포함 시 공백 제거, 영문은 대문자) | `전기 차` → `전기차`, `ai` → `AI` |
| 붙어 있는 키워드 분리 (`#`, 두 칸 이상 공백, `·`) | `자동차 전기차  소비촉진` → `자동차전기차`, `소비촉진` |
| 괄호 분리 | `외국인직접투자(FDI)` → `외국인직접투자`, `FDI` |
| 지역 단독 키워드 → 지역 칸 | `베트남` → `VN`, `두바이` → 도시 칸, `중동` → 권역 |
| 연도만 있는 키워드 → 언급 연도 칸 | `2026년` → `kw_year=2026` (`비전2030` 같은 이름은 그대로) |
| 국가·도시·권역 + 주제 복합어 분리 (긴 이름 먼저) | `인도네시아경제` → `ID` + `경제` |

## 지역 사전 (`geo_dict.csv`)

`name, type(국가/도시/권역), code, canonical, split` 5개 컬럼입니다. 이름을 추가하거나 고칠 때는 이 파일만 수정합니다.

- `code`: 국가는 ISO 2자리, 도시는 소속 국가(참고용, 국가 필터에는 넣지 않음), 권역은 권역 이름입니다.
- `split=N`: 단독 키워드일 때만 지역으로 봅니다. 앞부분만 같은 다른 단어가 잘리지 않게 할 때 사용합니다.
  - `피지`: `피지컬AI`가 피지(Fiji) + 컬AI로 잘리는 것 방지
  - `EU`, `UAE` 등 영문 약어: `EUDR`이 EU + DR로 잘리는 것 방지
  - `파리`, `리마` 등 두 글자 도시: `파리바게뜨` 같은 상호 보호
  - `미`, `러`, `중미`, `수단`: 다른 뜻이 있음

## 예외 목록 (`split_exceptions.csv`)

나라를 떼고 **남는 말이 목록의 말로 끝나면** 나누지 않고 통째로 주제어에 남깁니다 (국가 정보는 `geo_country`에 그대로 기록).
예: 목록에 `선거`가 있으면 `체코대통령선거`, `인도네시아국회의원선거`도 통째로 유지됩니다.

| 남는말 | 유형 | 예 |
|---|---|---|
| 사태, 전쟁, 선거, 대선, 제재, 위기 … | 사건 | 우크라이나사태, 중동전쟁, 미국대선, 러시아제재 |
| 무역관, 투자청, 관세청, 재무부, 위원회, 은행 … | 기관 | 워싱턴무역관, 태국투자청, 유럽중앙은행 |
| 정부, 대통령, 총리, 의회 … | 정부·인물 | 독일연방정부, 영국총리 |
| 엑스포, 박람회, 모터쇼, 페어, 포럼 … | 행사 | 오사카엑스포, 베이징모터쇼 |
| 두바이초콜릿 (단어 전체) | 고유명사 | 디저트 이름이라 두바이와 무관 |

`남는말` 칸에는 끝나는 말(사태) 또는 단어 전체(두바이초콜릿)를 적습니다. 목록은 이 파일만 고치면 됩니다.
`전시회`는 일반 주제(전시회 기사)로 세는 게 의미 있어 넣지 않았습니다. `센터`는 `데이터센터`까지 걸려서 넣지 않았습니다.

## 동의어 사전 (`synonyms.csv`)

같은 뜻의 다른 표기를 대표어 하나로 바꿉니다 (검색용·급증 계산용 주제어 모두). 칸: 표기 · 대표어 · 근거 · 표기_기사수 · 대표어_기사수.

- 후보: ① 원본 괄호 표기(전기차(EV)) ② 표기 유사(K뷰티 · K-BEAUTY) ③ 같은 기사 동시 등장(원자력 · 원전) → 사람이 확인
- 대표어 = 묶음 안에서 기사 수가 가장 많은 표기 (인공지능 254 → AI 532)
- 걸러 낸 것: 식품(ML)·화장품(NA)(단위·코드), FORD·GM·냉장고·세탁기(같이 나오지만 다른 말), 배터리·이차전지(넓이가 다름)
- 추가할 때는 한 줄씩 `표기,대표어,근거,,` 형식으로 넣으면 됩니다. 대표어가 다른 줄의 표기가 되면 안 됩니다(테스트로 확인).

## 불용어 목록 (`stopwords.csv`) — 기본은 비어 있음

**회의 결정(2026-10-14): 불용어 구분을 없애고, 보기 싫은 키워드는 사용자가 직접 블락합니다.**
넓은 말(수출·경제·전시회 등)을 미리 정하는 기준이 애매했기 때문입니다. 그래서 `stopwords.csv`는 칸만 남아 있고, 지금은 `kw_spike` = `kw_topic`입니다.

- 파일과 코드는 그대로 둡니다. 메인 화면 주요 이슈(모든 사용자 공통)에 넓은 말이 뜨면 **관리자 블락 목록**으로 이 파일에 한 줄씩 넣으면
  그 말은 급증 계산(`kw_spike`)에서만 빠지고 검색(`kw_topic`)에는 남습니다.
- 사용자별 블락은 키워드 정리 코드가 아니라 화면·알림 쪽에서 거릅니다 (테이블 `user_keyword_block`, 검토 문서 참고).
- 영향: 최근 52주 주요 이슈(키워드) 판정 136 → 159건 (넓은 말 23건 추가). 10/14 판정에 `투자진출` 추가.
- 예전 불용어 44개(무역 일반어·범위어·형식어)와 고른 근거는 git 기록(커밋 1cbc83c)에 남아 있습니다.

## ⑥ 대/중분류 (`topic_categories.csv`)

정리된 주제어(10건 이상, 984개)에 분류 틀(대분류 8 · 중분류 23)을 붙인 표입니다. 기사에는 `kw_category` 칸(대분류>중분류, 여러 개 가능)으로 붙습니다.

- 배정: ① 규칙(정확히 같은 말 → 포함하는 말) ② 글자만 겹쳐 틀린 규칙 결과는 수정 목록 ③ 규칙에 안 걸린 말만 LLM 판단 ④ 그래도 못 정하면 "검수 필요"(미분류) — 자세한 기준은 CLASSIFICATION_RULES.md
- 예전 불용어 43개도 분야를 배정 (수출 → 수출입 일반, 전시회 → 전시회·행사, 투자 → 투자·M&A …), 너무 넓은 15개(한국·글로벌·혁신 …)는 미분류
- 일부만 겹쳐 잘못 붙던 말은 직접 고침 (관광산업 ≠ 광산, 현지진출 ≠ 지진, 스마트홈 ≠ 마트, 해상풍력 ≠ 해상물류)
- 결과: 미분류 33개(3%) · 분야가 붙은 기사 12,504 / 14,607건
- 품목어(전기차·화장품 …)는 "산업·품목" 대분류로 두고 HS 코드로 연결합니다.

## 기사 집계 테이블(FR-906)과 급증 판정(FR-203·204) — `article_counts.py`

```powershell
python backend/app/services/news_keywords/article_counts.py --date 2026-10-14
```

| 결과 파일 (`data/news_keywords/`) | 내용 |
|---|---|
| `keyword_daily_counts.csv` | 날짜 × 국가 × 키워드(kw_spike) 기사 수 |
| `product_daily_counts.csv` | 날짜 × 국가 × 품목 기사 수, `unit` 칸으로 HS 6단위(기본)·4단위 구분 (지금은 1단계 HS만) |

- FR-203 급증 기사 알림은 `interest_alerts(키워드 집계, 품목 집계, 판정일, 관심 국가, products=관심 품목, keywords=관심 키워드)`로 계산합니다 (어제 ÷ 이틀 전까지 7일 일평균 ≥ 2.5, 관심 품목은 6단위면 6단위 집계, 4단위면 4단위 집계). 요구사항대로 품목과 키워드를 모두 봅니다.
- FR-204 품목 판정은 6단위·4단위 각각 계산합니다 (`type` 칸: 키워드 / 품목(HS6) / 품목(HS4)).
- 한 기사는 같은 키워드·품목을 1건으로 셉니다. 전체 기준 판정(FR-204)은 나라가 여러 개인 기사도 1건으로 셉니다.
- DB 적재·스케줄러 연결은 팀 확인 후 붙입니다.

## 알려진 한계

- 지역 이름이 다른 뜻으로 쓰인 경우는 구분하지 못합니다. (`두바이초콜릿`은 디저트 이름이지만 도시 칸에 두바이로 남음)
  그래서 도시는 국가 필터에 넣지 않습니다: `두바이` 키워드 기사 127건 중 122건은 이미 기사 국가가 UAE이고, 나머지는 디저트 기사였습니다.
- `한국`은 기사 대상 국가가 아니라 한국과의 관계를 뜻하는 경우가 많아 지역 사전에 넣지 않았습니다.
- `EV`·`ELECTRIC VEHICLE`·`전기차`처럼 같은 뜻의 다른 말은 다음 단계(동의어 사전)에서 통합합니다.

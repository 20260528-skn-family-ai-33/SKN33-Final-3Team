# 키워드 분류 기준 (동의어 · 대/중분류 · 예외 · 지역 · 불용어)

해외시장뉴스 키워드 정리에서 **무엇을 어떤 기준으로, 누가 정했는지**와 **그 결과를 다시 만드는 코드**를 정리한 문서입니다.
사전(csv)은 모두 코드로 다시 만들 수 있고, `build/verify.py`로 저장된 파일·나눠 준 검수 파일이 코드 결과와 같은지 확인합니다.

## 한눈에 보기

| 사전 | 파일 | 만드는 코드 | 규칙(자동) | 뜻으로 판단한 부분 (판단 주체) |
|---|---|---|---|---|
| 동의어 | `synonyms.csv` (94개 규칙) | `build/build_synonyms.py` | 대표어 = 기사 수가 가장 많은 표기 | 어떤 표기들을 같은 뜻으로 묶을지 (`GROUPS`, 근거 칸) — 괄호 표기·표기 유사는 데이터 근거, **같은 뜻 34개는 Claude 판단** |
| 동의어 후보 | `data/news_keywords/동의어_검수용.csv` (397줄) | `build/synonym_candidates.py` | 임베딩 유사도 · 동시 등장 · 1차 의견 규칙 | 없음 (후보만 뽑음, 확정은 팀 O/X) |
| 대/중분류 | `topic_categories.csv` (984개) | `build/build_categories.py` | 분류 틀의 대표 키워드와 일치·포함 | 규칙에 안 걸린 말의 분류 (`category_manual.csv` 364개, **Claude 판단**, 이유 기록) |
| 예외 목록 | `split_exceptions.csv` (73개) | 없음 (목록 자체가 기준) | 남는 말이 목록의 말로 끝나면 통째로 유지 | 어떤 말을 목록에 넣을지 (Claude 판단, 유형·이유 칸) |
| 지역 사전 | `geo_dict.csv` (346개) | 없음 (목록 자체가 기준) | 키워드 앞부분이 지명이면 분리 | 지명·종류·코드·권역 묶음·단독 전용 여부 (Claude 판단) |
| 불용어 | `stopwords.csv` (비어 있음) | — | 목록의 말은 급증 계산에서만 제외 | 회의 결정으로 없앰 → 사용자 키워드 블락 |

검수 파일 만들기: `build/review_files.py` → `data/news_keywords/review/` (동의어_검수용.xlsx, 동의어_랜덤100_검수용.xlsx, 대중분류_검수용.xlsx, 미분류_예시기사.xlsx)

```powershell
python backend/app/services/news_keywords/build/build_synonyms.py      # synonyms.csv
python backend/app/services/news_keywords/build/build_categories.py    # topic_categories.csv (keyword_clean.py 실행 후)
python backend/app/services/news_keywords/build/review_files.py        # 검수용 엑셀
python backend/app/services/news_keywords/build/verify.py --shared "나눠 준 폴더"   # 일치 확인
# 동의어 후보(임베딩)는 sentence-transformers가 있는 환경(llm_env)에서
python backend/app/services/news_keywords/build/synonym_candidates.py
python backend/app/services/news_keywords/build/verify.py --candidates
```

순서: `keyword_clean.py`(지역·예외·동의어 적용) → `build_categories.py`(주제어 기사 수로 분류표) → `keyword_clean.py` 다시(분야 칸 반영) → `article_counts.py`.

## 1. 정제 (규칙, `keyword_clean.py`)
- HTML 문자(`&#39;`)·해시태그(`#`)·따옴표 제거, 영문은 대문자로 (ai → AI, 원본은 보관)
- 두 칸 이상 띄어쓰기·괄호는 키워드를 나눔 (외국인직접투자(FDI) → 외국인직접투자, FDI). 한 칸 띄어쓰기는 한 단어 안인 경우가 많아 나누지 않음
- 연도만 있는 키워드(2026년)는 지우지 않고 언급 연도 칸으로. 이름 안의 연도(비전2030)는 주제어로 유지

## 2. 지역 사전 (`geo_dict.csv`)
- 칸: `name`(기사에 적힌 말) · `type`(국가/도시/권역) · `code` · `canonical`(대표 이름) · `split`
- 키워드 **앞부분**이 지명이면 떼어 냄: 중국경제 → 국가 CN + 경제
- `split=N`(44개): 짧아서 다른 말 앞부분과 겹치는 이름은 **키워드 전체가 그 이름일 때만** 지역으로 봄 (피지 ≠ 피지컬AI, 파리 ≠ 파리바게뜨, EU ≠ EUDR)
- 권역 묶음: 같은 지역의 여러 표기를 하나로 (동남아·동남아시아·아세안·ASEAN → 아세안)
- 국가 필터(`country_all`)는 **KOTRA 국가 칸 기준**. 국가 칸이 KOTRA 본사·전세계일 때만 키워드 속 나라로 보충. 도시는 국가 필터에 넣지 않음 (두바이 키워드 127건 중 122건은 이미 UAE, 나머지는 두바이초콜릿)
- 분류 작업 중 미분류에서 나온 지명 9개(타이베이, 허난성, 하이난, GBA, 연해주, 극동러시아, 극동, 타밀나두, INDIA)는 분야 대신 지역 사전에 추가
- **코드로 만들 수 없는 것:** 어떤 말이 지명인지, 어느 나라·권역인지는 목록으로만 정할 수 있음 → 파일 자체가 기준

## 3. 예외 목록 (`split_exceptions.csv`)
- 나라를 떼고 남는 말이 목록의 말로 **끝나면** 나누지 않고 통째로 유지 (우크라이나 + 사태 → "사태"만 남으면 무슨 사태인지 모름)
- 유형: 사건(사태·전쟁·제재…) · 기관(무역관·투자청·재무부…) · 정부·인물(대통령·총리…) · 행사(엑스포·박람회·포럼…) · 고유명사(두바이초콜릿)
- 기준 질문: "나라를 떼면 뜻이 사라지나?"
- **코드로 만들 수 없는 것:** 어떤 말이 사건·기관 이름인지는 뜻의 판단 → 목록(유형·이유 칸)으로 남김

## 4. 동의어 (`synonyms.csv`, `build/build_synonyms.py`)
- 묶음(`GROUPS`)마다 근거를 적음
  - **괄호 표기 (21)**: 원본에 "전기차(EV)"처럼 괄호로 함께 적힌 쌍 — 기자가 같은 뜻이라고 적은 것
  - **표기 유사 (39)**: 기호·띄어쓰기·대소문자·한글/영문만 다름 (K-뷰티 · K뷰티 · K-BEAUTY)
  - **같은 뜻 (34)**: 글자는 다르지만 뜻이 같다고 판단 (인공지능 → AI) — **Claude 판단, 팀 검수 대상**
- 대표어 = 묶음 안에서 기사 수가 가장 많은 표기 (동의어 적용 전 기준). 데이터에 없는 표기는 뺌
- 일부러 합치지 않은 것: 배터리 / 이차전지 (배터리가 더 넓음), 탄소중립 / 넷제로, FORD·GM, 냉장고·세탁기
- **코드로 만들 수 없는 것:** "두 말이 같은 뜻인가"는 규칙으로 정할 수 없음 (임베딩은 반대말·상위어도 비슷하다고 함) → 확정 목록(`GROUPS`)으로 남기고, 새 묶음은 후보 → 팀 O/X → `GROUPS`에 추가

### 동의어 후보 (`build/synonym_candidates.py`)
- 임베딩: 기사 10건 이상 주제어를 `intfloat/multilingual-e5-base`로 벡터화(오프라인) → 단어마다 가장 가까운 3개 → 유사도 0.93 이상 (232쌍)
- 동시 등장: 기사 5건 이상 단어끼리 함께 나온 기사 5건 이상 · 동시등장률 50% 이상 → 그중 임베딩 0.9 이상 (71쌍). 넓은 말(예전 불용어 44개)은 아무 말과나 같이 나와 제외
- 1차 의견(규칙): 반대말 쌍 → "주의: 반대 뜻" / 짧은 말 + 접미사(시장·산업·법·화…) → "주의: 범위가 다를 수 있음" / 한쪽이 다른 쪽을 포함 → "주의: 포함" / 나머지 → "같은 뜻 후보"
- 회의 결정: 미반영 후보에서 **랜덤 100개**(시드 20261014)를 확인해 문제가 없으면 "임베딩 기준 이상 → 자동 동의어" 규칙으로 처리
- 새 키워드(사전에 없는 말)는 자동으로 합치지 않고 관리자가 확인 후 처리

## 5. 대/중분류 (`topic_categories.csv`, `build/build_categories.py`)
- 대상: 정리된 주제어(kw_topic) 중 기사 10건 이상 (984개). 기사에는 `kw_category` 칸으로 **주제어마다** 분야를 붙임 (한 기사에 여러 개 가능)
- 분류 틀: 대분류 8 · 중분류 23. 중분류마다 그 분류를 대표하는 키워드 목록(`TAX`)

| 대분류 | 중분류 |
|---|---|
| 무역·통상 | 관세·무역규제 · 협정·통상정책 · 통관·인증·표준 · 공급망·물류 · 수출입 일반 |
| 경제·시장 | 거시경제 · 시장·소비 동향 · 인구·노동 |
| 기업·투자·진출 | 투자·M&A · 진출·마케팅 · 전시회·행사 · 창업·취업 |
| 정책·제도 | 정부 정책·지원 |
| 기술·디지털 | AI·소프트웨어 · 디지털·플랫폼 · 로봇·자동화·스마트 · 통신·보안 |
| 에너지·환경 | 에너지 전환 · 화석연료·자원 · 친환경·ESG·기후 |
| 산업·품목 | 품목 (분류 대신 HS 코드로 연결) |
| 기관·인물·사건 | 인물·기관·기업 · 사건·이슈 |

- 배정 순서 (먼저 맞는 것)
  1. **직접** (349): `category_manual.csv`에 있는 말 — 규칙으로 안 되는 말을 뜻으로 정함 (판단·이유 칸)
  2. **규칙(일치)** (397): 대표 키워드와 정확히 같음
  3. **규칙(포함)** (205): 대표 키워드(2글자 이상)를 포함 — 틀 위에서부터 먼저 맞는 분류
  4. **검수 필요** (33): 어디에도 안 맞거나, 뜻이 너무 넓어 정하지 않은 말
- 포함 규칙의 실수를 직접 배정으로 바로잡은 예: 관광산업(≠ 광산), 현지진출(≠ 지진), 해상풍력, 파리협정. 스마트홈은 대표 키워드에서 '마트'를 빼서 해결
- 예전 불용어 43개: 28개 배정(수출 → 수출입 일반, 전시회 → 전시회·행사, 투자 → 투자·M&A, 경제 → 거시경제 …), 15개는 너무 넓어 검수 필요(산업·한국·기술·동향·혁신 …)
- 회의 결정: 미분류는 단어마다 예시 기사 10건(`미분류_예시기사.xlsx`)을 보고 분야를 정함
- **코드로 만들 수 없는 것:** 규칙에 안 걸린 말의 분야, 포함 규칙이 틀린 경우 → `category_manual.csv`(364줄: 직접 349 + 판단해서 미분류로 둔 15)에 이유와 함께 남김. 표에 없는 새 주제어는 분야가 비고, 주기적으로 표에 추가

## 6. 불용어 (`stopwords.csv`)
- 회의 결정(2026-10-14): 넓은 말을 미리 정하는 기준이 애매해 **기본 불용어를 없앰** → 사용자가 보기 싫은 키워드를 직접 블락
- 파일·코드는 **관리자 블락 목록**으로 유지: 넣은 말은 급증 계산(`kw_spike`)에서만 빠지고 검색(`kw_topic`)에는 남음
- 예전 44개와 고른 근거(기사 비율 · 산업분야 고름 · 52주 급증 판정 + 의미 기준)는 git 기록(커밋 1cbc83c)에 있음

## 7. 품목 · 집계 (규칙)
- 품목: KOTRA HS 칸 → HS 6단위(요구사항 기본) · 4단위, 없으면 KOTRA 산업분류. 키워드·제목 → HS 사전 연결은 HS 사전 완료 후
- 집계(FR-906): 날짜 × 국가 × 키워드 / 품목(6·4단위). 한 기사는 같은 키워드·품목을 1건으로
- FR-204: 최근 7일 ÷ 직전 8주 주평균 ≥ 3 (0이면 1) · FR-203: 어제 ÷ 이틀 전까지 7일 일평균 ≥ 2.5 (0이면 1), 관심 국가 × 관심 품목·키워드

## 코드로 남길 수 없는 것 (정리)
뜻을 판단해야 하는 일은 규칙 코드로 계산할 수 없어 **판단 결과를 목록(csv·코드 상수)으로 남기고, 판단 주체와 이유를 적었습니다.**
같은 판단을 자동으로 하려면 LLM이 필요하고, 그래도 확정은 사람이 합니다.

| 판단 | 남긴 곳 | 개수 |
|---|---|---|
| 같은 뜻 동의어 묶음 | `build/build_synonyms.py`의 `GROUPS` (근거 = 같은 뜻) | 34 |
| 규칙에 안 걸린 말의 분야 · 포함 규칙 수정 | `category_manual.csv` | 364 |
| 분류 틀(중분류 23개)과 대표 키워드 | `build/build_categories.py`의 `TAX` | 23 |
| 사건·기관·행사 이름 (예외) | `split_exceptions.csv` | 73 |
| 지명·종류·코드·권역·단독 전용 | `geo_dict.csv` | 346 |
| 동의어 후보의 같은 뜻 여부 | 팀 O/X (검수 파일) | 303 |

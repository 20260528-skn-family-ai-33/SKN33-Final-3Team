# 키워드 분류 기준 (README)

해외시장뉴스 키워드를 정리할 때 **무엇을, 어떤 기준과 순서로, 어디까지 규칙(코드)으로 하고 어디서 LLM 판단·팀 결정을 썼는지** 정리한 문서입니다.

## 0. 원칙 (2026-10-22 정리)

1. **규칙을 먼저 모두 대조합니다.** 글자로 판단할 수 있는 것(정확히 같음, 끝말, 포함, 괄호 표기, 기호만 다름)은 코드로 처리합니다.
2. **규칙으로 안 되는 것만 LLM 판단을 씁니다.** "뜻이 같은가", "어느 분야인가"처럼 뜻을 알아야 하는 것입니다. 결과는 코드 안 목록으로 남겨, 실행 중에는 LLM을 부르지 않습니다 (결과가 매번 같음).
3. **팀 검수 결과는 규칙으로 옮기고, 옮길 수 없는 것만 코드 안 예외 목록에 둡니다.** 검수 파일·규칙 csv는 읽지 않습니다.
4. **규칙으로도 예외 목록으로도 못 정한 말은 관리자 분류 대상(PENDING)** 입니다 (DB `keyword_topic`, 기사 3건 이상).
5. 추정(규칙(포함)·LLM 판단)도 확정합니다 (팀 결정 2026-10-22). 틀린 것은 관리자가 DB에서 고치거나 예외 목록에 넣습니다.

> 이 작업의 LLM 판단(분야 목록 `CATEGORY_LLM`, 동의어 묶음 중 `LLM 판단`)은 개발 중 Claude(Claude Code)가 단어의 뜻과 함께 나온 주제어를 보고 내렸습니다.
> 상위어 후보의 임베딩만 OpenAI API(`text-embedding-3-large`)로 계산합니다.

## 2. 정제 (규칙, `keyword_clean.py`)
- HTML 문자(`&#39;`)·해시태그(`#`)·따옴표 제거, 영문은 대문자로 (ai → AI, 원본은 보관)
- 두 칸 이상 띄어쓰기·괄호는 키워드를 나눔 (외국인직접투자(FDI) → 외국인직접투자, FDI). 한 칸 띄어쓰기는 한 단어 안인 경우가 많아 나누지 않음
- 연도만 있는 키워드(2026년)는 지우지 않고 언급 연도 칸으로. 이름 안의 연도(비전2030)는 주제어로 유지

## 3. 지역 분리 (`rule_data.GEO_DICT`)
- **규칙:** 키워드 앞부분이 사전의 지명이면 떼어 냄 (중국경제 → 국가 CN + 경제). `split=N`인 이름(44개)은 키워드 전체가 그 이름일 때만 (피지 ≠ 피지컬AI, 파리 ≠ 파리바게뜨, EU ≠ EUDR). 가장 긴 지명이 맞았는데 남는 말이 한 글자면 원문 유지하고 더 짧은 지명으로 자르지 않음 (인도네시아산 ≠ 인도 + 네시아산, 유럽연합법 ≠ 유럽 + 연합법)
- **국가 필터(`country_all`):** KOTRA 국가 칸 기준. 국가 칸이 KOTRA 본사·전세계일 때만 키워드 속 나라로 보충. 도시는 국가 필터에 넣지 않음 (두바이 키워드 127건 중 122건은 이미 UAE, 나머지는 두바이초콜릿)
- **권역 묶음:** 같은 지역의 여러 표기를 하나로 (동남아·동남아시아·아세안·ASEAN → 아세안)
- **LLM 판단:** 어떤 말이 지명인지, 어느 나라·권역인지, 짧아서 단독 전용으로 둘지
- 목록 자체가 기준이라 만드는 코드는 없음 → 목록을 고치면 바로 반영

## 4. 예외 목록 (`rule_data.SPLIT_EXCEPTIONS`)
- **규칙:** 나라를 떼고 남는 말이 목록의 말로 **끝나면** 나누지 않음 (우크라이나 + 사태 → "사태"만 남으면 무슨 사태인지 모름)
- **LLM 판단:** 목록에 넣을 말 — 사건(사태·전쟁·제재…) · 기관(무역관·투자청·재무부…) · 정부·인물 · 행사(엑스포·박람회·포럼…) · 고유명사. 기준 질문: "나라를 떼면 뜻이 사라지나?"

## 5. 동의어 (`build/build_synonyms.py` → `data/news_keywords/synonyms.csv`)

### 순서
① 확정 묶음 `GROUPS` → ② 예외 같은 말 `SYNONYM_EXTRA` → ③ 접미사 규칙 → ④ 같은 기본어 규칙 → 사슬(A→B→C)은 마지막 대표어로 정리 (정보통신기술산업 → 정보통신기술 → ICT).
먼저 정한 쪽이 이깁니다 (반대 방향 연결은 넣지 않아 순환이 생기지 않음: 예외 제조 → 제조업이 있으면 접미사 규칙 제조업 → 제조는 무시).

### `판정` 칸
| 판정 | 기준 |
|---|---|
| `규칙: 괄호` (20) | 원본 키워드에 "A(B)"로 실제로 함께 적힌 쌍 |
| `규칙: 표기` (13) | 기호·띄어쓰기·대소문자를 지우면 같은 글자 (K뷰티 = K-뷰티, CHAT GPT = 챗GPT) |
| `LLM 판단` (61) | 위 규칙으로 확인되지 않는 `GROUPS` 묶음 — 번역어(K-BEAUTY = K-뷰티), 약어(EV 묶음의 전기자동차), 같은 뜻 다른 말(인공지능 = AI) |
| `규칙: 접미사` (363) | **OO산업 · OO시장 · OO업 → OO** (화장품시장 → 화장품, 건설업 → 건설). 기본 단어 2글자 이상 · 주제어로 5건 이상 |
| `규칙: 같은 기본어` (7) | 기본 단어가 5건 미만이어도 OO산업 · OO시장 · OO업끼리는 같은 말 → 기사 많은 쪽 (수산산업 = 수산업) |
| `예외: 같은 말` (58) | 규칙으로 못 옮기지만 팀이 같은 말로 정한 쌍 (`SYNONYM_EXTRA`: 경제성장 = 경제성장률, 푸드 = 식품, 디지털화 = 디지털 …) |

- 접미사 규칙의 이유: 같은 대상을 범위만 다르게 부른 말. 따로 두면 ① "화장품" 검색에서 화장품시장 기사가 빠지고 ② 급증 건수가 쪼개지고 ③ HS 사전도 기본 품목어로 연결됨
- 규칙 제외 기본어 (`SUFFIX_EXCLUDE_BASE`): 너무 넓거나 형용사·다른 뜻 — 서비스, 미래, 유망, 혁신, 전략, 고급, 고부가가치, 해외, 지원, 선물, 투자, 신흥(신흥시장 ≠ 신흥산업), 규슈(지명), 노동
- **끝에 률·율·화·성·품이 붙은 말은 규칙으로 묶지 않습니다.** 시험해 보니 161쌍 중 틀린 쌍이 많았음 (화장 ≠ 화장품, 현대 ≠ 현대화, 쓰촨성 ≠ 쓰촨, 달러화·유로화). 팀이 같은 말로 정한 것(경제성장률 · 디지털화 · 지속가능성 · 의약품 …)만 `SYNONYM_EXTRA`에
- 막는 것: 반대말(`rule_data.SYNONYM_OPPOSITES`: 수출 ↔ 수입, 구직 ↔ 구인, 재사용 ↔ 재활용 …)과 묶지 않을 쌍(`SYNONYM_BLOCK`: 온라인시장 ≠ 온라인, 의료미용시장 ≠ 의료미용 — 상위어 팀 지정대로 가게)은 어떤 규칙으로도 묶지 않음
- 최종 사전 확인: 막을 쌍이 다른 연결을 거쳐 같은 대표어가 되거나, 예외 같은 말이 서로 다른 대표어로 갈라지면(반대말을 예외에 넣은 경우 포함) **멈추고 목록을 알려 줌** (`SynonymConflict`) → 예외 목록을 정리한 뒤 다시 실행
- 일부러 합치지 않은 것: 배터리 / 이차전지 (배터리가 더 넓음), 탄소중립 / 넷제로, FORD·GM, 냉장고·세탁기

### 팀 검수에서 규칙으로 옮긴 것 (2026-10-19 검수 → 2026-10-22 코드화)
- 팀 O 판정 중 접미사·같은 기본어 규칙으로 나오는 것은 규칙으로, 나머지 58쌍(+ 제조 → 제조업 방향)은 `SYNONYM_EXTRA`로
- 팀 X 판정 중 규칙이 묶는 것: 온라인시장 ≠ 온라인 · 의료미용시장 ≠ 의료미용은 `SYNONYM_BLOCK`으로, 신흥산업 ≠ 신흥시장은 `SUFFIX_EXCLUDE_BASE`(신흥)로
- 재사용 = 재활용은 팀이 O로 했지만 반대말 목록과 부딪쳐 따로 둠 (같은 말로 바꾸려면 반대말 목록에서 빼고 `SYNONYM_EXTRA`에 추가)
- 결과: 이전 사전(516개) 중 515개가 같고, 규칙으로 7개가 새로 생김

### 동의어 판단 기준 (예외 목록에 추가할 때)
- 핵심 질문: **"두 키워드를 합쳤을 때 같은 이야기의 기사들이 모이나?"** — 사전 뜻이 아니라 기사에서의 쓰임, 그리고 **앞으로 들어올 기사에서도 같은 뜻일까**까지
- 같은 말: 같은 대상을 다르게 부르는 말(표기·번역·같은 뜻, 기사에서 같은 용도: 참관 = 참관기)
- 같은 말 아님: 넓은 범주 ⊃ 그 안의 하나(식음료 ⊃ 음료 → 상위어로) · 종류·세부 주제(스킨케어, 탄산리튬, 전기차보조금 → 상위어로) · 반대·짝(수출금지 ↔ 수입금지) · 관련 있지만 다른 것(석유 ~ 석유화학)

## 5-2. 상위어 (`build/hierarchy_candidates.py` → `build/build_hypernyms.py` → `data/news_keywords/hypernyms.csv`) — 팀 결정 2026-10-21
- 동의어 자동 검수(임베딩 0.96) 대신 **하위어를 상위어로 바꿔** 키워드로 씀. 동의어 다음 단계, 바꾸기 전 말은 `kw_sub` 칸에 남김
- 후보 (모두 규칙, 다시 만들 수 있음)
  1. 동의어 사전의 쌍 (접미사 규칙 줄은 바로 위 기본 단어와의 쌍도)
  2. 임베딩 이웃: 기사 10건 이상 주제어를 OpenAI `text-embedding-3-large`로 임베딩, 말마다 가장 가까운 3개 → 유사도 상위 232쌍
  3. 동시 등장: 넓은 말(`rule_data.BROAD_WORDS`, 예전 불용어 44개) 빼고, 둘 다 기사 5건 이상 · 함께 5건 이상 · 적은 쪽 기사의 50% 이상 → 유사도 상위 71쌍
  (232·71은 예전 후보(e5 모델 유사도 0.93 / 0.9 이상)와 같은 개수. 임베딩은 `data/news_keywords/word_vectors.npz`에 저장해 새 말만 다시 계산)
- 판정 순서 (위가 우선)
  1. 반대·짝: 반대말 쌍 — 상하위 아님
  2. 글자 포함: 짧은 말 = 상위어. 뒤에 산업·시장·업 = 범위 / 앞에만 붙음 = 종류(화장품 ⊃ 기초화장품) / 뒤에 다른 말 = 세부 주제(전기차 ⊃ 전기차보조금)
     · 뒤에 성·품·률·율·회·케어만 붙으면 같은 대상(의약 = 의약품) — 상하위 아님
  3. 같은 뜻 묶음(GROUPS): 같은 수준 (EV = 전기차)
  4. 동시 등장: 글자가 안 겹치면 P(넓은 말|좁은 말) ≥ 0.3 · P(좁은 말|넓은 말) ≤ 0.1 · 넓은 말 기사 3배 이상 → 좁은 말 = 하위어 (자동차 ⊃ 완성차)
  5. 그 밖: 판단 보류 (사전에 넣지 않음)
  6. **상위어가 넓은 말(`BROAD_WORDS`: 수출·투자·경제·진출·혁신 …)이거나 한 글자면 제외** — 투자진출 → 투자, 소비재 → 소비처럼 넓은 말로 바꾸면 검색·급증 판정에서 뜻이 흐려짐
- 코드 안 예외가 마지막에 덮어씀: 팀 지정 하위어(`MANUAL_CHILDREN`: 미용·온라인쇼핑·의료·의약품·전기차·카페·반려동물) · 기존 사전 유지(`KEPT_CHILDREN` 51개: 규칙 후보에는 안 나오지만 팀이 적용한 기존 사전에 있던 연결) · 각각 상위어(`MANUAL_SEPARATE`: 물가·발전소·서비스업·신소재·전기차·소비트렌드·온라인쇼핑·화장품·현대화·리튬이온배터리·석유화학·스마트폰 / 쇼핑 ≠ 온라인쇼핑 / 바이오·바이오매스, 외국인·외국인투자, 그린·그린딜, 스마트·스마트그리드, 데이터·데이터센터, 전기차·미래차)
- 사전: 상위어가 둘 이상이면 예외 → 기사 많은 쪽 · 사슬은 맨 위까지 · 동의어 대표어 기준으로 다시 맞춤 · 각각 상위어로 정한 쌍이 합쳐지거나 사슬이 돌아오면 멈춤 (`HypernymConflict`)
- 분야(⑤)는 상위어와 하위어 모두로 붙임 (경제성장률이 상위어로 바뀌어도 거시경제 유지)
- 이전 사전(171줄)과 비교: 146줄 같음 · 상위어가 좁아짐 6 · 넓은 상위어라 빠짐 19 · 규칙으로 새로 생김 33 (틀려 보인 6개는 `MANUAL_SEPARATE`로 분리, 팀 결정 2026-10-22)

- 추정(규칙(포함)·LLM 판단)도 확정 (팀 결정 2026-10-22, 팀 검수 기준 정확도 약 89% · 80%)
- 팀이 미분류로 정한 말도 규칙을 적용 (팀 결정 2026-10-21) → 이전 분류표의 미분류 40개가 규칙으로 분야를 얻음
- 끝말 규칙은 "모든 포함 규칙을 끝말 우선으로" 바꾸면 오히려 정확도가 낮아져(87% → 86%) 팀 검수에서 확인된 끝말만 넣음
- 규칙 수정 예: 관광산업("광산" 포함 ✗ → 품목), 현지진출("지진" ✗ → 진출·마케팅), 리튬이온배터리("리튬" ✗ → 품목), 파리협정("협정" ✗ → 친환경·ESG·기후)
- LLM 판단 기준: "이 주제어가 들어간 기사가 주로 어떤 분야 이야기인가" — 품목·상품이면 산업·품목, 행사면 전시회·행사 …
- 기사에는 `kw_category` 칸으로 **주제어마다** 분야를 붙임 (한 기사에 여러 개 가능)
- 분류표에 없는 주제어(기사 10건 미만·새 단어)도 기사 처리 때 **같은 판정 함수(`category_rules.classify`)** 를 씀 → 분류표를 다시 만들어도 결과가 같음
- **미분류 목록(`data/news_keywords/unclassified_topics.csv`)**: 분야가 정해지지 않은 주제어 전체 — 주제어 · 고유 기사 수 · 미분류 이유 · 최근 기사 3건, 기사 수 많은 순

### 분류 판단 기준 (예외 목록에 추가할 때)
- 근거: 그 주제어가 나온 최근 기사의 제목·같이 나온 주제어
- **뜻이 하나로 분명한 말만 분야를 붙임.** 애매하면 미분류. 미분류여도 그 기사에는 다른 구체적인 주제어로 분야가 붙음
  - 미분류 예: 범위어(사회) · 꾸밈말(천연) · 대상에 따라 뜻이 갈리는 말(인상: 임금·관세·수수료) · 시기어(상반기·여름)
- 서비스·사람 대상(관광·호텔·의료관광)은 HS 품목이 아니라 시장·소비 동향

### 분야의 쓰임과 한계
- 분야는 **단어 단위**: 드럭스토어 = 시장·소비 동향이면 "드럭스토어 화재" 기사에도 붙음 (기사 내용은 보지 않음)
- 그래서 분야는 확정 분류가 아니라 **검색의 보조 정보**로 씀: ① 국가·기간·품목 필터 + 키워드·의미 검색으로 후보 → ② 사용자 블락 → ③ 1차 점수(분야 일치는 가점) → ④ 상위 20건을 LLM이 기사 문맥으로 재순위 → 요약
- 분류표 대상은 기사 10건 이상 주제어(748개). 표에 없는 말도 같은 규칙을 적용해 **기사의 95%(13,806 / 14,607건)에 분야가 붙음**. 기준은 `--min-articles`로 바꿀 수 있음

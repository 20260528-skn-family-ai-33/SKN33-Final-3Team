# 키워드 분류 기준 (README)

해외시장뉴스 키워드를 정리할 때 **무엇을, 어떤 기준과 순서로, 어디까지 규칙(코드)으로 하고 어디서 LLM 판단을 썼는지** 정리한 문서입니다.
모든 사전(csv)은 `build/` 코드로 다시 만들 수 있고, `build/verify.py`로 저장된 파일·나눠 준 검수 파일이 코드 결과와 같은지 확인합니다.

## 0. 원칙

1. **규칙을 먼저 모두 대조합니다.** 글자로 판단할 수 있는 것(정확히 같음, 포함, 괄호 표기, 기호만 다름)은 코드로 처리합니다.
2. **규칙으로 안 되는 것만 LLM 판단을 씁니다.** "뜻이 같은가", "어느 분야인가"처럼 뜻을 알아야 하는 것입니다.
3. **LLM 판단은 결과를 목록 파일로 남깁니다.** 서비스 실행 중에는 LLM을 부르지 않고 이 목록만 읽습니다 (결과가 매번 같음).
4. **확정은 사람이 합니다.** 규칙(포함)·LLM 판단 결과는 팀 검수 대상입니다.

> 이 작업의 LLM 판단은 개발 중 Claude(Claude Code)가 단어의 뜻과 함께 나온 주제어를 보고 내렸습니다. API로 자동 실행한 것이 아니므로
> 같은 판단을 다시 하려면 아래 목록 파일을 쓰거나, 같은 기준으로 LLM에 다시 물어야 합니다.

## 2. 정제 (규칙, `keyword_clean.py`)
- HTML 문자(`&#39;`)·해시태그(`#`)·따옴표 제거, 영문은 대문자로 (ai → AI, 원본은 보관)
- 두 칸 이상 띄어쓰기·괄호는 키워드를 나눔 (외국인직접투자(FDI) → 외국인직접투자, FDI). 한 칸 띄어쓰기는 한 단어 안인 경우가 많아 나누지 않음
- 연도만 있는 키워드(2026년)는 지우지 않고 언급 연도 칸으로. 이름 안의 연도(비전2030)는 주제어로 유지

## 3. 지역 분리 (`geo_dict.csv`)
- **규칙:** 키워드 앞부분이 사전의 지명이면 떼어 냄 (중국경제 → 국가 CN + 경제). `split=N`인 이름(44개)은 키워드 전체가 그 이름일 때만 (피지 ≠ 피지컬AI, 파리 ≠ 파리바게뜨, EU ≠ EUDR)
- **국가 필터(`country_all`):** KOTRA 국가 칸 기준. 국가 칸이 KOTRA 본사·전세계일 때만 키워드 속 나라로 보충. 도시는 국가 필터에 넣지 않음 (두바이 키워드 127건 중 122건은 이미 UAE, 나머지는 두바이초콜릿)
- **권역 묶음:** 같은 지역의 여러 표기를 하나로 (동남아·동남아시아·아세안·ASEAN → 아세안)
- **LLM 판단:** 어떤 말이 지명인지, 어느 나라·권역인지, 짧아서 단독 전용으로 둘지. 분류 작업 중 미분류에서 나온 지명 9개(타이베이·허난성·하이난·GBA·연해주·극동러시아·극동·타밀나두·INDIA)도 추가
- 목록 자체가 기준이라 만드는 코드는 없음 → 파일을 고치면 바로 반영

## 4. 예외 목록 (`split_exceptions.csv`)
- **규칙:** 나라를 떼고 남는 말이 목록의 말로 **끝나면** 나누지 않음 (우크라이나 + 사태 → "사태"만 남으면 무슨 사태인지 모름)
- **LLM 판단:** 목록에 넣을 말 — 사건(사태·전쟁·제재…) · 기관(무역관·투자청·재무부…) · 정부·인물 · 행사(엑스포·박람회·포럼…) · 고유명사. 기준 질문: "나라를 떼면 뜻이 사라지나?"

## 5. 동의어 (`synonyms.csv`, `build/build_synonyms.py`)
- 묶음(`GROUPS`)마다 근거를 적고, 대표어 = 묶음 안에서 기사 수가 가장 많은 표기 (동의어 적용 전 기준)
- **`판정` 칸은 코드가 직접 검사합니다**
  - `규칙: 괄호` (20): 원본 키워드에 "A(B)"로 실제로 함께 적힌 쌍
  - `규칙: 표기` (13): 기호·띄어쓰기·대소문자를 지우면 같은 글자 (K뷰티 = K-뷰티, CHAT GPT = 챗GPT)
  - `LLM 판단` (61): 위 규칙으로 확인되지 않는 것 — 번역어(K-BEAUTY = K-뷰티, NETZERO = 넷제로), 약어(EV 묶음의 전기자동차), 같은 뜻 다른 말(인공지능 = AI, 코로나바이러스 = 코로나19)
- 일부러 합치지 않은 것: 배터리 / 이차전지 (배터리가 더 넓음), 탄소중립 / 넷제로, FORD·GM, 냉장고·세탁기

### 접미사 규칙 (규칙, `build_synonyms.py`의 `suffix_pairs`)
- **OO산업 · OO시장 · OO업 → OO** (예: 화장품시장·화장품산업 → 화장품, 자동차산업 → 자동차, 건설업 → 건설, 뷰티산업·뷰티시장 → 뷰티)
- 이유: 같은 대상을 범위만 다르게 부른 말. 따로 두면 ① "화장품" 검색에서 화장품시장 기사(38건 중 23건)가 빠지고 ② 급증 건수가 쪼개져 3배 기준을 못 넘거나 주요 이슈에 같은 이슈가 두 번 뜨고 ③ HS 사전도 기본 품목어로 연결됨
- 조건: 기본 단어(OO)가 2글자 이상이고 주제어로 5건 이상 있을 때 (1글자: 물산업 ≠ 물류)
- 예외 (`SUFFIX_EXCLUDE_BASE`): 기본 단어가 너무 넓거나 형용사·다른 뜻 — 서비스, 미래, 유망, 혁신, 전략, 고급, 고부가가치, 해외, 지원, 선물, 투자, 규슈(지명), 노동(노동법·노조 포함 → 노동시장은 고용시장과 팀 검수로 묶음)
- 팀이 X·△로 표시한 쌍은 규칙으로도 묶지 않음 (팀 판단이 규칙보다 우선). 원본 키워드(kwrd)는 그대로 보관
- 순서: ① GROUPS → ② 팀 검수 O → ③ 접미사 규칙 → 사슬(A→B→C)은 마지막 대표어로 정리 (예: 정보통신기술산업 → 정보통신기술 → ICT)

### 팀 검수 반영 (`build/import_synonym_review.py` → `synonym_decisions.csv`)
- 여러 사람이 나눠 채운 엑셀을 함께 읽음: `--file A.xlsx --rows 2-150 --file B.xlsx --rows 151-304`
- 같은 쌍을 다르게 표시했거나 한 표기에 O가 두 개면 알려 주고 멈춤 → 엑셀에서 정리 후 다시 실행
- O는 동의어로, X·△는 반영 안 함 (규칙으로도 안 묶음). 의견 칸(대표어 변경 등)은 따로 출력해 사람이 반영

### 팀 검수 결과 (2026-10-15 반영)
- 미반영 후보 303쌍 전체 O 79 · X 205 · △ 19 (2~150행 팀원, 151~304행 허유나) → `synonym_decisions.csv`
- 기능 기준으로 재검토해 O로 조정 (같은 대상인데 두 키워드가 같은 기사에 거의 같이 붙지 않아, 따로 두면 검색에서 빠지는 기사): 풍력발전 → 풍력(19건), 상표권 → 상표(23건), 참관 → 참관기(12건), 의약 → 의약품(11건), 태양광발전 → 태양광(5건) · 기능성식품 → 건강기능식품은 △
- 종류·세부는 구분: 신차 ≠ 자동차(완성차 = 자동차), 스킨케어·기초화장품 ≠ 화장품, 탄산리튬 ≠ 리튬, 전기차보조금 ≠ 전기차, 화장품규제 ≠ 화장품
- 같은 대상은 묶음: 화장품수출·식품수출 → 화장품·식품, 관세율 → 관세, 여행 → 관광, 푸드·음식 → 식품, 재사용 → 재활용

### 동의어 검수 기준 (사람이 O/X/△ 할 때)
- 핵심 질문: **"두 키워드를 합쳤을 때 같은 이야기의 기사들이 모이나?"** — 사전 뜻이 아니라 기사에서의 쓰임, 그리고 **앞으로 들어올 기사에서도 같은 뜻일까**까지
- O: 같은 대상을 다르게 부르는 말(표기·번역·같은 뜻, 사전 뜻은 달라도 기사에서 같은 용도: 참관 = 참관기) · 같은 대상 + 산업·시장·업(규칙이 자동 처리)
- X: 넓은 범주 ⊃ 그 안의 다른 하나(식음료 ⊃ 음료, 건설 ⊃ 건축) · 종류·세부 주제(스킨케어, 탄산리튬, 전기차보조금, 영화관 — 넓은 말 키워드가 이미 같이 붙어 있어 합칠 이득 없이 세부 검색만 잃음) · 반대·짝(수출금지 ↔ 수입금지, 구인 ↔ 구직) · 관련 있지만 다른 것(석유 ~ 석유화학, 원자재 ~ 원자력)
- △: 애매하면 → 반영 안 하고 회의에서 결정. 넓은 말 → 좁은 말(북극 → 북극항로, 법인 → 법인설립)은 앞으로의 기사 때문에 △/X
- 한 표기에 O는 하나만. 대표어가 이상하면 O + 의견 칸에 바꿀 대표어

### 동의어 후보 (`build/synonym_candidates.py`) — 규칙·임베딩만, LLM 없음
- 임베딩: 기사 10건 이상 주제어를 `intfloat/multilingual-e5-base`로 벡터화(오프라인) → 단어마다 가장 가까운 3개 → 유사도 0.93 이상 (232쌍)
- 동시 등장: 기사 5건 이상 단어끼리 함께 나온 기사 5건 이상 · 동시등장률 50% 이상 → 그중 임베딩 0.9 이상 (71쌍). 넓은 말(예전 불용어 44개)은 제외
- 1차 의견(규칙): 반대말 쌍 → "주의: 반대 뜻" / 짧은 말 + 접미사(시장·산업·법·화…) → "주의: 범위가 다를 수 있음" / 한쪽이 다른 쪽을 포함 → "주의: 포함" / 나머지 → "같은 뜻 후보"
- **자동 O (팀 결정 2026-10-14):** 근거가 임베딩(동시 등장 제외)이고 유사도 **0.96 이상**인 미반영 후보 23쌍은 "팀 확인(O/X)"을 O로 미리 채움(`AUTO_O_SIM`, 의견 칸에 "자동 O" 표시). 미반영 303쌍 전체는 `동의어_미반영_검수용.xlsx`에서 하나씩 O/X/△ (자동 O 줄도 확인)
- 회의 결정: 미반영 후보에서 **랜덤 100개**(시드 20261014)를 확인해 문제가 없으면 "임베딩 기준 이상 → 자동 동의어" 규칙으로 처리. 새 키워드는 관리자가 확인 후 처리

중분류마다 그 분류를 대표하는 키워드 목록이 `TAX`에 있습니다 (예: 관세·무역규제 = 관세 반덤핑 세이프가드 수입규제 …). 틀과 대표 키워드는 기사에 자주 나오는 주제어를 보고 정했습니다 (LLM 판단, 대분류 8개는 분류초안 v0의 틀).

### 배정 순서 (`배정방법` 칸)
| 순서 | 배정방법 | 기준 | 개수 | 남긴 곳 |
|---|---|---|---|---|
| 1 | 규칙(일치) | 주제어가 대표 키워드와 정확히 같음 | 390 | 코드 |
| 2 | 규칙(포함) | 대표 키워드(2글자 이상)를 포함 — 틀 위에서부터 먼저 맞는 분류 | 156 | 코드 |
| 3 | 규칙 수정 | 규칙 결과가 글자만 겹쳐 틀린 경우 바로잡음 (`규칙 결과` 칸에 원래 결과) | 8 | `category_rule_fixes.csv` (이유 포함) |
| 4 | LLM 판단 | **규칙에 하나도 안 걸린 말만** 뜻으로 배정 | 326 | `category_llm.csv` |
| 5 | 검수 필요 | 규칙·LLM 모두 못 정함 (뜻이 너무 넓음: 한국·산업·기술·여름 …) | 32 | — (미분류_예시기사.xlsx로 팀이 결정) |

- 규칙 수정 예: 관광산업("광산" 포함 → 화석연료·자원 ✗ → 품목), 현지진출("지진" ✗ → 진출·마케팅), 리튬이온배터리("리튬" ✗ → 품목), 파리협정("협정" ✗ → 친환경·ESG·기후), 발전(에너지 "발전"과 같은 글자지만 기사에서는 "경제 발전" 뜻이 많아 정하지 않음)
- LLM 판단 기준: "이 주제어가 들어간 기사가 주로 어떤 분야 이야기인가" — 품목·상품이면 산업·품목, 행사면 전시회·행사 …
- 예전 불용어 43개(회의 결정으로 불용어 없앰)도 같은 순서로 처리: 규칙 2개(정책·진출전략), 규칙 수정 1개(소비자), LLM 판단 25개(수출 → 수출입 일반, 전시회 → 전시회·행사 …), 못 정함 15개(발전 포함)
- 기사에는 `kw_category` 칸으로 **주제어마다** 분야를 붙임 (한 기사에 여러 개 가능)

### 대상: 기사 10건 이상 주제어 (912개, 접미사 규칙·팀 검수 동의어로 합쳐진 뒤) — 괜찮은가?
| 기준 | 주제어 수 | 전체 언급 중 | 분야가 하나라도 붙을 수 있는 기사 |
|---|---|---|---|
| **10건 이상 (지금)** | 912 | 50% | 86% |
| 5건 이상 | 2,133 (+1,149) | 60% | 90% |
| 3건 이상 | 4,006 | 68% | 93% |

- 주제어 종류(24,233)의 대부분은 몇 번만 나오는 말이라, 10건 이상 주제어만으로 **기사의 86%(12,638건)에 분야가 붙습니다.** 분야는 화면 필터·이슈 묶음용 보조 기능이라 충분하다고 판단했습니다.
- 5건 이상으로 내리면 기사 기준 +4%p인데, 늘어나는 1,149개 중 규칙으로 되는 건 422개뿐이고 727개는 LLM 판단·검수가 필요합니다. 기준은 `--min-articles`로 바꿀 수 있습니다.
- 표에 없는 드문 주제어는 분야가 비고(미분류), 검색은 임베딩이 보완합니다.

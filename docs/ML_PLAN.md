# 수출 유망 시장 ML 계획서

작성: 2026-10-19 · 갱신: 2026-10-21 · 관련 이슈: #20 · 상태: 기존 시장 모델 오류 수정·가상 검증 완료, 실제 학습 및 미진출 기능은 미완료

미진출 시장 발굴은 프로젝트 범위에 포함한다. 별도 후보·라벨·모델 개발과 팀 결정 사항은 [ML_NEW_MARKETS_PLAN.md](ML_NEW_MARKETS_PLAN.md)를 따른다. 아래 A·B는 기존 수출 시장을 대상으로 한다.

실행 방법은 [ML_USAGE.md](../backend/app/ml/ML_USAGE.md)에 있다.

## 1. 목표

| 기능 | 입력 | 출력 |
|---|---|---|
| ① 유망 품목 추천 | 국가 | 그 국가에서 유망한 HS6 품목 Top 5 |
| ② 유망 국가 추천 | HS6 품목 | 그 품목이 유망한 국가 Top 5 |
| ③ 시장 유형 분류 | 국가 + HS6 품목 | 5개 시장 유형 중 하나 |

"유망"은 **한국의 해당 국가·품목 수출이 앞으로 12개월 동안 얼마나 늘어날지**로 정의한다.

## 2. 설계 핵심

- 학습 단위는 **(국가 c, HS6 p, 기준월 t) 한 행**이다.
- ①과 ②는 같은 문제라서 **모델 A 하나**로 해결한다.
  - 모델 A가 모든 (c, p) 쌍에 유망도 점수를 매긴다.
  - ①은 국가 c로 걸러 점수 상위 5개 품목을, ②는 품목 p로 걸러 상위 5개 국가를 보여준다.
  - 이렇게 하면 두 기능의 결과가 서로 어긋나지 않는다.
- ③은 같은 행·피처를 쓰는 **모델 B**(다중분류)로 해결한다.
- 기존 시장 A·B는 피처 파이프라인을 공유한다. 미진출 C는 같은 기준정보를 재사용하되 후보와 정답을 별도로 구성한다.

### 3.2 외부 (CSV, DB 미적재) — 검토한 수집 자료

학습·배치 예측 입력은 `data/external/`의 CSV로 둔다. 이번 코드·문서 변경에는 데이터 파일을 포함하지 않는다.

| 데이터 | 경로 | 범위 | 내용 |
|---|---|---|---|
| CEPII BACI (HS22) | `data/external/baci/baci_imports_hs22.csv` | 2022~2024 | 수입국·HS6별 전세계 수입액, 한국발 수입액 |
| UN Comtrade | `data/external/comtrade/comtrade_imports_<연도>.csv` | 2025 (114개국) | BACI에 아직 없는 최신 연도 보충, 같은 컬럼 |

- 국가 키는 ISO2지만 시드 미등록 국가·지역이 있으므로 연결 상태를 확인해야 한다. 현재 BACI의 PM은 국가 시드와 연결되지 않는다.
- 외부 데이터에만 있던 4개국(KR·KP·XK·JG)은 `country`에 추가했다. 한국(KR)과 채널제도 합계(JG)는 `SPECIAL`이라 피처 대상에서 빠진다.
- 수집 방법, 자동 갱신(매월 1일 04:00), 로그 위치는 [EXTERNAL_COLLECT_USAGE.md](../backend/app/scheduler/collectors/external/EXTERNAL_COLLECT_USAGE.md)에 있다.

**외부 데이터가 필요한 이유:** 관세청 데이터에는 한국이 이미 수출하는 쌍만 있다. 그래서 상대국의 시장 규모, 한국 점유율, 아직 진출하지 않은 시장은 BACI·Comtrade 없이는 알 수 없다.

## 4. 전처리

1. **HS 판본 통일**: `hs_code_correlation`으로 HS2017 잔존 코드를 HS2022로 바꾼다. n:n 관계는 `group_code` 단위로 합친다.
2. **국가 필터**: `country_role='COUNTRY'`만 쓴다.
3. **일회성 거래 처리**: R1은 다음 달이 있어야 확정된다. 기준월에는 원금액을 쓰고 앞선 월만 보정한다. 미래 정답의 마지막 월도 원금액을 쓴다.
4. **롤링 12개월 집계**: 성장 비교에 과거 24개월이 필요하다. 수정본은 입력 국가·HS6 쌍의 월별 금액 누락을 0으로 채우지 않고 오류로 중단한다. 확인된 0만 명시적으로 입력한다. 수집 범위 전체의 완료 증명과 미진출 상태 판정은 별도 개발 대상이다.
5. **증가율**: `log1p(최근12M) − log1p(직전12M)`로 계산한다. 외부 시장 성장·점유율 변화·GDP 성장률과 모델 A의 정답은 학습 행에서 추정한 1%·99% 경계로 자른다. 모든 증가율에 일괄 적용하는 것은 아니다.
6. **최소 규모 필터**: 최근 12개월 수출액이 $100k 미만인 쌍은 학습에서 뺀다. 이는 기존 코드의 조건이며, 변경하려면 별도 검토가 필요하다.
7. **외부 데이터 시점 맞춤**: `availability.csv`에 현재 값·버전의 실제 사용 가능일을 기록하고 기준월 말까지 공개된 값만 연결한다. 메타정보가 없으면 임의로 1년 지연을 가정하지 않고 오류를 낸다. 전년값과 WDI 보충값의 사용 가능일도 고려한다. 검토한 파일 묶음에는 이 메타정보가 없었다. 팀원 보유본의 값·버전에 대응하는 정보를 확인해야 한다.
8. **스케일링 없음**: 트리 모델이라 필요 없다. `region_id`, `hs2`는 범주형 그대로 쓴다.
9. **CSV 읽기 주의**: 나미비아 코드가 `NA`라서 `keep_default_na=False, na_values=[""]`로 읽어야 결측으로 바뀌지 않는다.

## 5. 피처 (X) — 기준월 t 시점에 알 수 있는 값만

| 그룹 | 피처 | 원천 |
|---|---|---|
| 쌍 실적 | `log_exp_12m`, `growth_12m`, `growth_3m`, 거래 있던 월 수, 변동계수(CV), 이상치 비율, 단가 추세 | export_monthly |
| 쌍 비중 | c 전체 수출 중 p 비중, p 전체 수출 중 c 비중 | export_monthly |
| 국가 | 한국→c 총수출 증가율, `region_id`, 환율 12개월 변화율·변동성 | export_monthly, country, fx_daily |
| 국가 거시 | GDP, GDP 성장률, 인구, 1인당 GDP | WDI |
| 품목 | 한국 p 전세계 수출 증가율, p를 수출하는 국가 수, `hs2` | export_monthly, hs_code |
| 시장 규모 | c의 p 수입액(log), 수입 증가율, 한국 점유율, 점유율 변화 | BACI·Comtrade |
| 뉴스 | 최근 90일 (p,c)·(p,*) 기사 수, 직전 90일 대비 증감 | news_product_daily |

## 6. 모델 A — 유망도 (기능 ①②)

- **y**: `log1p(수출[t+1..t+12]) − log1p(수출[t-11..t])` (이후 12개월 성장)
  - 해석하기 쉬운 쪽이 필요하면 이진 분류로 바꾼다: "다음 12개월 성장률 상위 20% & 최소 규모 이상 = 1"
- **모델**: scikit-learn `HistGradientBoostingRegressor` (LightGBM과 같은 히스토그램 부스팅, 새 의존성 없음)
  - 순위 품질을 더 올려야 할 때만 LightGBM `LGBMRanker`(group=국가)를 검토한다.
- **현재 분할**: 정답이 있는 마지막 기준월을 평가하고, 그보다 12개월 이상 앞선 기준월만 학습한다. 별도 Dev/Holdout 분리는 추가 개발 대상이다.
- **평가**: 국가별 품목 및 품목별 국가 Precision@5, NDCG@5. 후보가 기존 최소 개수 10 미만인 그룹은 평가하지 않으며 평가 그룹 수를 기록한다.
- **반드시 비교할 기준선**: "작년 성장률 상위 5개"를 그대로 고르는 규칙. 이걸 못 이기면 ML을 쓸 이유가 없다.

## 7. 모델 B — 시장 유형 (기능 ③)

| 라벨 | 유형 | 기준 (시장 성장 × 한국 점유율) |
|---|---|---|
| 0 | 고성장·선점형 | 변동형이 아니며 시장 성장·한국 점유율이 높음 |
| 1 | 고성장·진입형 | 시장 성장 높음, 한국 점유율 낮음 |
| 2 | 성숙·유지형 | 다른 규칙에 해당하지 않는 나머지 유효 행 |
| 3 | 정체·축소형 | 시장과 한국 실적 모두 감소 |
| 4 | 변동·일회성형 | 미래 수출 CV가 높음. 이상치 비율은 현재 라벨 규칙에 미사용 |

- **라벨은 미래 구간으로 만든다**: y = t+1~t+12 실적에 위 규칙을 적용한 유형, X = t까지의 과거 피처.
  - 현재 X에 규칙을 적용해 라벨을 만들면 모델이 그 규칙을 외울 뿐이고, 그럴 거면 규칙만으로 충분하다.
- **모델**: `HistGradientBoostingClassifier(class_weight='balanced')`
- **규칙 적용 순서**: 변동성 상위 20% → 4, 시장 성장 상위 40%이면서 점유율 상위 40% → 0, 시장 성장 상위 40% → 1, 시장·한국 모두 감소 → 3, 나머지 → 2
- **미래 시장 성장**: 연간 외부 데이터라 "기준월+6개월이 속한 해 vs 그 전해"로 근사한다. 외부 데이터가 없는 연도·쌍은 라벨을 만들지 않는다.
- **평가**: 기준선과 공통 행·동일 5개 유형의 macro-F1을 비교한다. 모델의 전체 유효 행 점수·혼동행렬도 별도로 기록한다. 학습 정답은 평가 기준월까지 공개된 것만 사용한다.
- **임계값**(성장 "높음"·점유율 "높음"의 기준)은 학습 기간 분포의 분위수로 정하고, `metadata.json`에 저장한다. 현재 `service_option` RULE과 연결되지는 않는다.
- **대안**: K-Means(k=5) 군집 후 이름 붙이기. `model_run` 테이블이 국가 군집용으로 이미 설계돼 있다. 다만 군집 경계를 설명하기 어렵다.

- 모델·평가: `data/ml/models.joblib`, `data/ml/metadata.json` (피처·기준값·평가 결과, git 제외)

## 10. 위험과 확인할 점

- **관세청 실적 적재 범위**: 과거 문서의 일부 월 적재 기록은 현재 팀원 보유 자료의 상태를 증명하지 않는다. 실제 입력인 `export_monthly` 또는 대응 CSV의 기간·국가·HS 범위와 수집 완료 기록을 확인해야 한다. 과거 24개월 피처·미래 12개월 정답 및 시간 분할에 충분한 관측이 필요하다.
- **학습 시점 수**: 데이터가 2022년부터라서 과거 24개월 이력과 미래 12개월을 고려하면 데이터가 2026-09까지일 때 정답이 있는 기준월은 22개, 그중 평가용 12개월 간격을 빼면 학습 기준월은 10개다. 과적합을 막기 위해 피처 수를 늘리기보다 기준선 대비 성능부터 확인한다.
- **Comtrade 최신 연도는 일부 국가만 있다**: 2025년은 114개국이다. 이 연도를 피처로 쓸 때는 결측 처리 규칙이 필요하다.
- **금액 기준이 출처마다 다르다**: BACI는 조정된 FOB, Comtrade 수입은 CIF, 관세청은 FOB다. 관세청 FOB와 BACI도 신고·조정·집계 차이로 금액 일치를 보장하지 않는다. [CEPII 방법론](https://www.cepii.fr/pdf_pub/wp/2010/wp2010-23.pdf).
  그래서 성장률은 같은 출처끼리만 비교하고(BACI 다음 해는 연결 연도 Comtrade와 비교), 금액 수준보다 비율·증가율 위주로 쓴다.
- **HS 판본 연결**: 원본 문서에 기록된 HS2017 잔존 코드 150개(2022·2023년)는 팀원 보유 자료와 대조하고, 대응표로 판본을 통일한다.

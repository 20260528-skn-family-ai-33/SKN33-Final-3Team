# Writer 독립 Holdout 100문항 평가

2026년 11월 10일, **Writer(Compose)의 최종 운영 모델을 `gpt-6-luna`로 확정했다.** 독립 Holdout에서 전체 91/100, 처음 평가한 신규 문항에서 61/67을 통과했다. `gpt-5.6-luna`는 각각 90/100과 58/67이었다. 수정 후 Dev 생성형에서도 93/94 대 90/94였으며, 두 평가 모두 6-luna의 중앙 응답시간과 추정 비용이 더 낮았다. 기존 환경변수 `API_COMPOSE_MODEL`에 값을 지정하면 해당 값이 우선하며, 미설정 기본값은 선정 모델과 같다. [Dev 100문항 수정 전후 비교](WRITER_DEV_EVALUATION.md)

## 독립 출제와 블라인드 판정

신규 출제자는 Writer 입출력 계약을 사용해 합성 입력과 문항별 정답을 작성했다. Dev 문항·실답변·이전 성적은 공유하지 않았다. 전체 100문항은 Dev와 ID 또는 정규화한 질문 문자열이 겹치지 않았다. 입력과 정답을 각각 봉인하고 두 후보에서 모델명 외에 동일한 첫 요청을 전송한 95쌍을 확인했다. 추론 강도는 low, 출력 상한은 일반 Compose 3,000토큰·문장형 Compose 6,000토큰이었다.

두 후보의 답변 200건을 저장한 뒤, 문항별로 모델명을 무작위 A/B로 가렸다. 출제와 분리된 검수 에이전트가 실제 결론·설명을 필수 사실·금지 주장·기사 출처와 대조했다. 금액은 Writer의 만 달러 반올림 표기를 인정했다. 기존 문항 `SYN-HO-006`의 접수일과 조회 연도는 충돌해 사용자가 확정한 봉인 정답의 2025년·2024년을 기준으로 채점했고 두 답변 모두 통과했다.

출제할 때 예상한 경로는 모델 호출 96건·코드 응답 4건이었다. `EXT-HO-041`에서 통계 조회가 실패해 기사만 남자 Compose가 고정 안내를 반환했다. 이 문항은 두 설정 모두 의미 실패로 집계했고, 실제 경로별 분모는 모델 호출 95건·코드 응답 5건이다.

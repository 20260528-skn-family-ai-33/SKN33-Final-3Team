# Writer Dev 100문항 평가

2026년 11월 10일, **Writer(Compose)의 최종 모델을 `gpt-6-luna`로 선정했다.** 수정 후 Dev 100문항에서 99건을 통과했다. 같은 조건의 `gpt-5.6-luna`는 96건을 통과했다. 최종 두 후보는 같은 설정으로 독립 Holdout에서도 검증했다. [독립 Holdout 100문항 결과](WRITER_HOLDOUT_EVALUATION.md)

## 같은 문항으로 비교한 수정 전후 결과

기존 6문항과 추가 94문항으로 구성한 합성 Dev다. 서비스가 모델을 호출하는 문항은 94개, 코드가 정해진 답변을 반환하는 문항은 6개였다. 표의 분수는 의미 통과 수와 평가 수다. 시간은 모델 호출 문항의 중앙값이며 비용은 해당 호출 전체의 토큰 사용량과 실행 당시 표준 단가로 계산한 USD 추정액이다.

| --- | --- | --- | --- | --- | --- | --- |

월별 집계값과 미집계가 섞인 질문에는 각 월과 해당 금액 또는 미집계를 짝지어 답하고, 소계를 제시할 때 전체 기간 합계 산출 가능 여부도 밝히도록 Writer 프롬프트에 한 문장을 추가했다. 수정 전후에 같은 입력과 같은 의미 채점 기준을 사용했다. 두 Luna 모델 모두 각 실행에서 재시도와 실패 후 대체 응답이 0건이었다.

초기 비교에는 `gpt-4.1-mini`도 포함했다. 이 모델은 호출 문항 94개 가운데 첫 초안 93개가 수용됐고, 재시도 1회와 대체 응답 1건이 발생했다. 수정 후 두 Luna 모델과 같은 절차로 확정한 mini의 의미 통과율은 없다.

## 판정 방법과 남은 실패

질문별 필수 사실·금지 주장과 실제 결론·설명을 대조했다. 복합 질문은 각 하위 결론의 수치와 출처를 해당 질문에 연결해 판단했다. 질문이 증감 방향만 요구하면 방향과 금액의 정확성을 인정했고, 월별 집계 여부를 물으면 각 월을 명시해야 통과로 판정했다. 금액·인용 번호가 답변에 있는지 확인하는 자동 검사와 의미 판정을 별도로 기록했다.

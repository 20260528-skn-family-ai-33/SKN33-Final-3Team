# Borderless Sellers 개인정보 처리방침

> 초안입니다. `[ ]` 표시는 확정 전 값이며, 공개 전 법률 검토가 필요합니다.
> 시행일: 2026년 11월 20일

Borderless Sellers 운영팀(이하 "운영자")은 「개인정보 보호법」 제30조에 따라 이용자의 개인정보를 보호하고 고충을 신속히 처리하기 위해 이 방침을 공개합니다.

## 주요 내용 요약
- **수집:** 이름, 이메일, 비밀번호, 관심 품목·국가, AI 질문·답변, 접속 기록
- **목적:** 회원 관리, 통계·AI 분석·리포트·알림 제공
- **보유:** 탈퇴 후 1개월 뒤 파기
- **해외 전달:** AI 답변을 위해 질문이 OpenAI로 전달됩니다
- **광고:** 광고성 정보를 보내지 않습니다

## 1. 개인정보의 처리 목적
운영자는 다음 목적으로만 개인정보를 처리합니다. 목적이 바뀌면 필요한 동의를 다시 받습니다.
1. 회원 가입·식별, 로그인, 계정 찾기, 비밀번호 재설정, 부정 이용 방지
2. 수출입 통계와 기사 조회, 관심 범위에 맞춘 화면 제공
3. 질문을 분석해 답변과 리포트를 제공하는 AI 분석
4. 정기 리포트 발행과 서비스 알림 제공

이 서비스의 AI 기능은 무역 통계와 해외시장 기사를 분석하기 위한 것입니다.

## 2. 처리하는 개인정보 항목과 근거
**동의를 받아 처리하는 항목** (「개인정보 보호법」 제15조제1항제1호)

| 구분 | 항목 |
|---|---|
| 회원가입 (필수) | 이름, 이메일, 비밀번호(암호화 저장) |
| 서비스 이용 | 관심 품목·국가, 시작 화면, 구독 설정, 알림 설정, 차단 키워드 |
| AI 분석 | 입력한 질문, 생성된 답변, 리포트 |
| 알림 (선택) | 동의 일시, 약관 버전, 동의·철회 이력 |

**서비스 이용 중 자동으로 생성되는 항목:** 접속 IP 주소, 접속 일시, 최근 로그인 일시, 서비스 이용 기록, 세션 쿠키

**입력창 주의:** 질문을 저장하기 전에 이메일 주소와 전화번호 형식은 가려서 저장합니다. 그래도 모든 개인정보를 걸러낼 수는 없으니 주민등록번호, 계좌번호, 건강 정보, 영업 비밀, 다른 사람의 정보를 입력하지 마세요.

## 3. 만 14세 미만 아동
서비스는 만 14세 이상만 가입할 수 있으며, 만 14세 미만 아동의 개인정보를 알면서 수집하지 않습니다.

## 4. 처리 및 보유 기간
| 항목 | 기간 |
|---|---|
| 회원 정보, 관심·구독·알림 설정 | 탈퇴 후 1개월 |
| AI 질문·답변 | 회원이 대화를 삭제할 때, 또는 탈퇴 후 1개월 |
| 리포트 | 탈퇴 후 1개월 |
| 접속 기록 | [보관 기간 확인 필요] |

다른 법령에 보관 의무가 있으면 그 기간 동안 보관합니다.

## 5. 파기 절차와 방법
보유 기간이 끝나거나 목적을 달성하면 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다. 탈퇴 후 1개월 동안은 회원 목록과 서비스 이용에서 제외한 상태로 보관합니다.

## 6. 제3자 제공
운영자는 개인정보를 제3자에게 제공하지 않습니다. 법령에 근거가 있는 경우는 예외입니다.

## 7. 처리 위탁
| 수탁자 | 위탁 업무 |
|---|---|
| OpenAI | AI 답변 생성 (8번에서 안내) |
| [서버 운영 업체 확인 필요, 예: AWS] | 서버와 데이터베이스 운영 |
| Google (Gmail) | 계정 찾기·임시 비밀번호 메일 발송 |

## 8. 개인정보의 국외 이전
AI 답변을 만들기 위해 아래와 같이 개인정보 처리를 국외에 위탁합니다.

| 항목 | 내용 |
|---|---|
| 법적 근거 | 「개인정보 보호법」 제26조, 제28조의8제1항제3호 (계약 이행을 위한 처리 위탁·보관) |
| 이전 항목 | 입력한 질문, 대화 맥락, 질문 처리에 필요한 조건 |
| 이전 국가 | [미국, OpenAI 계약 기준 확인 필요] |
| 시기와 방법 | AI 분석을 요청할 때, 암호화된 네트워크로 전송 |
| 이전받는 자 | OpenAI [법인명과 연락처 확인 필요] |
| 이용 목적 | 질문 해석, 답변 생성 |
| 보유·이용 기간 | [OpenAI API 정책 기준 확인 필요] |
| 거부 방법과 효과 | AI 분석을 이용하지 않으면 이전되지 않습니다. 이 경우 통계와 기사 조회는 이용할 수 있고 AI 분석은 이용할 수 없습니다. 회원 탈퇴도 요청할 수 있습니다. |

**AI 학습:** 운영자는 입력한 질문으로 AI 모델을 학습하지 않습니다. [OpenAI 측 학습 미사용 여부 계약 기준 확인 필요]

## 9. 안전성 확보 조치
- 비밀번호 암호화 저장(복호화할 수 없는 방식)
- 접근 권한 제한과 관리자 처리 이력 기록
- 로그인 세션 쿠키 보호(스크립트 접근 차단)
- 질문 저장 전 이메일 주소와 전화번호 형식 가림
- 전송 구간 암호화 [운영 서버 HTTPS 적용 확인 필요]

## 10. 쿠키
로그인 상태 유지를 위해 세션 쿠키를 사용합니다. 분석이나 광고 목적의 쿠키와 제3자 행태정보 수집은 사용하지 않습니다. 브라우저 설정에서 쿠키를 막을 수 있지만, 막으면 로그인할 수 없습니다.

## 11. 정보주체의 권리와 행사 방법
이용자는 언제든지 개인정보 열람, 정정, 삭제, 처리 정지, 동의 철회를 요구할 수 있습니다. 비밀번호, 관심 품목·국가, 알림 설정 변경과 대화 삭제는 서비스 화면에서 직접 할 수 있습니다. 그 밖의 요청은 아래 연락처로 보내 주시면 지체 없이 조치합니다.

## 12. 자동화된 결정
서비스의 AI 답변은 참고 정보이며, 이용자의 권리나 의무에 중대한 영향을 주는 결정을 자동으로 내리지 않습니다.

## 확정 사항

Dev151 요약 검수의 19문항·22건에 대한 사용자 결정을 별도 기록했다. 기존 질문·조건·정답과 검색·평가 결과를 덮어쓰지 않았다.

- 요약 보류 14건, 범위 축소 2건, 다른 근거 기사로 대체 1건, 답변 참조 유지 3건, 부분 요약 반환 1건, 기존 승인 부분 정답의 요약 복원 1건이다.
- 인플레이션 위험은 사용자가 요청한 고물가·가격 모니터링 범위로 유지한다. 전기차 산업 전반이나 통화정책의 물가·환율 인과로 확대하지 않는다.
- 추천은 해당 기사가 실제 제시한 내용으로 제한한다. 일반적인 인증·시장 진출 조언을 특정 개정 규정의 이행 절차로 바꾸지 않는다.
- 참조 유지와 직접 원인 입증을 구분한다. 기사의 원래 제도·산업·지표·기간을 명시하고, 다른 질문 대상의 원인·효과로 바꾸지 않는다.
- 같은 질문에 맞는 기존 조건 내 대체 근거가 확인되어 질문 삭제는 진행하지 않았다. 이미 반환된 기사를 중복 추가하지 않는다.
- 복합 질문은 승인된 일부 요소에 직접 답하는 근거를 유지한다. 다른 요소를 설명하지 않는다는 이유만으로 이미 승인된 부분 정답을 취소하지 않는다.

## 반영 상태와 다음 검증

이번 반영은 사용자 결정 및 근거가 확인된 수정 요약안의 기록이다. 모델이 같은 출력을 재현했거나 검수가 자동 통과했다고 표시하지 않는다. 답변 참조 유지 승인을 Recall 정답 추가 승인으로 간주하지 않는다. 기존 모델 출력·실패 기록을 보존한다.

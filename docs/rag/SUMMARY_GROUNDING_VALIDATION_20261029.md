# 기사 요약 근거 검증 보완 — 2026-10-29

## 변경

원문을 모델이 다시 쓰는 방식 대신, 모델이 원문 청크 번호를 선택하면 서버가 해당 문자열을 그대로 발췌한다. 기존 근거 ID·본문 버전·문자열 포함 검증, 요청 조건, 검색 순위, 반환 기사 수, 1회 출력 재시도와 전체 마감 시각을 유지한다.

요약은 질문의 일부에 직접 답하는 근거만 사용하고, 다른 지표·주체·기간·제도의 설명을 질문에 적용하지 않도록 지시한다. 생성 후 질문 대상과 문장 대상을 비교하고, 문장 전체가 연결된 발췌로 뒷받침되는지 별도 검사한다. 통과하지 못한 문장만 제외한다. 검사 응답 누락·형식 오류는 정상적인 보류로 숨기지 않는다. 모델과 프롬프트 버전이 캐시 키에 포함되어 이전 요약 캐시를 재사용하지 않는다.

## 남은 제한

모델 검사는 사실성의 확정 보장이 아니다. 새 요약 중 의미·관련성 의심 17건과 보류 재검토 5건, 합계 19문항·22개 기사 조합이 남았다. 기존 승인된 부분 정답의 요약 누락도 포함하며 정답 승인을 취소하지 않았다. 추가 모델 판정의 모순과 적용되지 않는 필드 오류는 원시 기록으로 보존했고, 명백한 오경고는 별도로 대조해 제외했다.

검사에 추가 모델 호출이 필요하므로 실제 서비스 전체 성능 검증이 남는다. 발췌는 선택 청크 전체라 기존의 짧은 발췌보다 길 수 있다. 본문 전체 또는 외부 원문의 진위를 검증한 것으로 표시하지 않는다.

내부 원문과 응답을 포함한 비교 자료는 Git에 포함하지 않고 Desktop 프로젝트의 `data/rag/evaluation/dev159_execution_20261029_v1/summary_validation_v6/`에 보존한다. `comparison.json`, `human_review.json`, `report.html`, `assistant_review.json`에서 결과와 남은 검수를 확인한다. 이전 단계와 실패 결과도 별도 경로로 유지한다.

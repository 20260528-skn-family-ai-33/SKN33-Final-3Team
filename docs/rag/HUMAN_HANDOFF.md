# RAG 검수 안내

[실행 방법](README.md)과 [완료 기준](IMPLEMENTATION_PLAN.md)을 따른다. 로컬 기사 원문·정답 검수 이력·실험 색인은 저장소에 포함하지 않는다.

같은 Dev set으로 Baseline과 실패 결과를 보존하고 한 번에 한 조건만 변경한다. Holdout은 설정 확정 후 최종 검증에만 사용한다. 합성 시험 통과와 실제 품질·서비스 통합 검증을 구분한다. 초기 모델과 1,000자·150자 설정의 우수성은 비교 실험으로 확정되지 않았다.


## 작업 재개 상태 — 2026-10-28

공통 본문 컬렉션은 `total_article`이다. 이전 컬렉션 구분 계획과 실험 기록은 당시 이력이며 현재 검색 계약으로 되돌리지 않는다.

로컬 평가 자료는 기존 Desktop 작업본에 보존하고 이번 코드 이관·커밋에 포함하지 않았다.

- 기존 Dev 20문항과 승인 후보 22건을 유지한다. 전체 정답 목록의 완전성 확정과 Recall 측정은 별도다.
- KOTRA 묶음은 기존 Dev-001~010과 신규 Dev-021~110의 100문항이다. 기존 Dev-011~020까지 보존한 합본은 110문항이다.
- 신규 90문항은 미승인이다. 사전 분류는 보류 2건·추가 근거 필요 7건·적합 81건이며, 적합 분류가 사용자 승인이나 추가 정답 조사 완료를 뜻하지 않는다.
- 다음 사용자 검수는 신규 질문의 전제·조건·근거와 대표 후보 확정이다. 그 뒤 문항별 추가 정답 조사와 고정 Dev 비교를 진행한다.
- 실제 50문항 Holdout, 실제 서비스 호출 경로·성능 검증은 완료로 간주하지 않는다.

본문·키워드 재구축과 실패 복구의 코드 검증 결과는 [후속 변경 이관 기록](FOLLOWUP_TRANSFER_20261028.md)을 따른다.
